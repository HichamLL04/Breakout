# Breakout

[Breakout](https://es.wikipedia.org/wiki/Breakout_(videojuego)) es un videojuego arcade desarrollado por Atari, Inc. y lanzado al mercado el 13 de mayo de 1976. Fue creado por Nolan Bushnell y Steve Bristow, influenciados por el videojuego de 1972 *Pong*, también de Atari.  

En 1978 se distribuyó la versión para el Atari 2600 y en 1983 la versión para MSX. Posteriormente fue mejorado en videojuegos como *Super Breakout*.

## Sobre el proyecto

Breakout es el tercero en este reto llamado [**The 20 Games Challenge**](https://20_games_challenge.gitlab.io/games/pong/), siendo el objetivo esta vez aprender a reutilizar código pero aumentando la complejidad del mismo.

El principal error en este proyecto fue la incapacidad de usar múltiples *input players*, debido a que el WebGL exportado por Unity y el sistema que lo permite ejecutar aquí solo se enfocan en uno de los sistemas de input, forzándome a crear una nueva *build* específicamente para el juego en la página.

## Jugabilidad

Este juego solo se puede jugar usando el teclado. Los controles son los siguientes:

- **Mover a la izquierda**
  - Presiona **A** o la **flecha izquierda (←)**.
- **Mover a la derecha**
  - Presiona **D** o la **flecha derecha (→)**.
- **Lanzar la pelota**
  - Presiona **W** o la **flecha arriba (↑)**.
